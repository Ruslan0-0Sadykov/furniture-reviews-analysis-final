# Анализ отзывов покупателей мебели

Воспроизводимый учебный Data Science-проект по 12 905 исходным отзывам из 2ГИС, Google и Яндекса. После очистки осталось 12 585 записей. Проект проверяет пять бизнес-гипотез, формирует графики и статистические таблицы, готовит плоский датасет для Yandex DataLens и собирает Word-отчёт.

## Результаты

| Гипотеза | Итог | Ключевой результат |
|---|---|---|
| H1: сервис чаще качества вызывает негатив | подтверждена | 67,3% против 30,1%; скорректированный p-value < 0,001 |
| H2: быстрая доставка связана с позитивной оценкой | подтверждена | 86,8% позитивных при быстрой и 42,2% при медленной доставке; OR = 8,96 |
| H3: несоответствие описанию — главная причина претензий | не подтверждена | лидируют дефекты качества: 49,2%; несоответствие описанию: 0,4% |
| H4: отзывы о мягкой мебели длиннее и эмоциональнее | не подтверждена | оба эффекта направлены в противоположную сторону и малы |
| H5: цена связана с подробностью отзыва | не подтверждена | Spearman rho = -0,041; p = 0,582; цена найдена только в 1,42% записей |

Выводы H2 наблюдательные и не доказывают причинность. H3–H5 ограничены отсутствием структурированных полей категории, причины возврата и цены в исходных данных.

## Быстрый запуск

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_all.py
.venv\Scripts\python -m pytest -q
```

Скрипт `run_all.py` загружает локальные файлы из `data/raw`, очищает данные, рассчитывает признаки и статистику, сохраняет обработанные датасеты, графики, таблицы и Word-отчёт. Для воспроизводимости используется фиксированный `random_state = 42`.

Исходные XLSX намеренно исключены из Git. В `data/raw` должны находиться три файла: `reviews_2gis.xlsx`, `reviews_google.xlsx`, `reviews_yandex.xlsx`.

## YandexGPT

Необязательные секреты задаются только через `.env` по примеру `.env.example`. Клиент реализует маскирование PII, таймауты, повторные попытки, строгий structured output по JSON Schema, валидацию, кеш и журнал ошибок. По умолчанию LLM выключена (`YANDEX_GPT_MAX_REVIEWS=0`), поэтому базовый результат воспроизводится прозрачными правилами. После активации платёжного аккаунта минимальный тест 22 сентября 2026 года вернул HTTP 200; YandexGPT автоматически разметил ограниченную выборку из 54 отзывов — по 6 из каждой из 9 страт «источник × тональность». Повторная сборка использует кеш и не отправляет успешные запросы заново.

## Структура

- `src/` — загрузка, очистка, признаки, статистика, визуализация, YandexGPT и генерация отчёта;
- `notebooks/` — EDA, предобработка и проверка гипотез;
- `data/processed/` — очищенный и обогащённый наборы;
- `outputs/` — графики, метрики и таблицы аудита;
- `report/` — итоговый Word-отчёт;
- `datalens/` — датасет, словарь и спецификация аналитического монитора;
- `tests/` — автоматические тесты;
- `DECISIONS.md` — принятые методические решения;
- `FINAL_STATUS.md` — статус всех артефактов и известных блокеров.

## DataLens

Агрегированный `datalens/datalens_dataset_public.csv` и `dashboard_spec.md` готовы к безопасному внешнему импорту. Публичная выгрузка не содержит текстов отзывов, имён, профилей, адресов и идентификаторов отзывов. Сам дашборд не создан: авторизованная сессия DataLens не была подтверждена. Публичный доступ не включался.

Для повторной сборки публичных выгрузок из локальных артефактов запустите `python tools/build_public_exports.py`. Файлы уровня отдельного отзыва с текстами и авторами хранятся только локально и исключены из Git.

# Статус Yandex DataLens

Для внешнего использования подготовлен агрегированный `datalens_dataset_public.csv`: он не содержит текстов отзывов, имён, профилей, адресов, компаний и стабильных идентификаторов.

Автоматическое создание workbook, connection, dataset и dashboard не завершено: `https://datalens.yandex.cloud/` не ответил в отведённое время, а браузер вернул `ERR_CONNECTION_TIMED_OUT` до показа страницы авторизации. Публичный доступ не включался, URL дашборда не создавался.

Минимальное ручное завершение:

1. Открыть DataLens в обычном авторизованном браузере.
2. Создать workbook `Furniture Reviews Practice`.
3. Загрузить `datalens_dataset_public.csv`, создать connection и dataset.
4. Собрать карточки, графики и фильтры по `dashboard_spec.md`.
5. Проверить отсутствие строковых полей с отзывами и идентификаторов, затем опубликовать и сохранить URL.

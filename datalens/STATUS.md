# Статус Yandex DataLens

Для внешнего использования подготовлен агрегированный `datalens_dataset_public.csv`: он не содержит текстов отзывов, имён, профилей, адресов, компаний и стабильных идентификаторов. Автоматическое создание workbook, connection, dataset и dashboard не завершено, потому что в доступной браузерной среде нет подтвержденной авторизованной сессии Yandex DataLens. Публичный доступ не включался.
